Race-time model and pit-stop optimisation (Phase 6, DECISIONS.md D56-D66).

Race-time model

A strategy is a sequence of stints, each on one compound, separated by pit stops. Every stint starts on a NEW tyre (D61), so on the j-th lap of a stint the tyre age is j. The predicted time of race lap n, on compound c at tyre age j, is

t(n) = base_c + d_c(j) - k_fuel (n - 1)
  • base_c: lap time of a new tyre of compound c for a typical car, fuel-corrected to full fuel (D57, D60);
  • d_c(j): the degradation model of compound c (d(0) = 0);
  • -k_fuel (n - 1): the fuel effect added back (D62), so the total is a real race time. It sums to k_fuel N (N - 1) / 2 for EVERY strategy, so it never changes which strategy is best.

The total race time is the sum over all laps plus one pit loss per stop.

Optimising a one-stop race (pit lap L = number of laps on the first set)

(a) brute force: evaluate every feasible integer L (the reference); (b) continuous relaxation: extend the race time to real L, solve dT/dL = 0 with my central difference + secant (or Newton with my second difference), then round and check the neighbouring integers (D64).

Feasibility (D63): no stint may exceed the largest tyre age with enough data for its compound, so the models are never extrapolated far.

 106class LinearDegradation:
 107    """Degradation d(n) = rate * n with a rate set directly (no fitting).
 108
 109    Used by the sensitivity analysis to perturb a fitted linear wear rate
 110    (e.g. by +/- 2 standard errors) while keeping everything else fixed.
 111
 112    Parameters
 113    ----------
 114    rate : float
 115        Wear rate [s/lap], finite.
 116
 117    Example
 118    -------
 119    >>> LinearDegradation(0.06).degradation([10.0]).tolist()
 120    [0.6]
 121    """
 122
 123    def __init__(self, rate):
 124        # The wear rate must be a real number (booleans rejected).
 125        if isinstance(rate, bool) or not np.isfinite(rate):
 126            raise ValueError(f"rate must be a finite number, got {rate!r}.")
 127        self.rate = float(rate)
 128
 129    def degradation(self, tyre_age):
 130        """Degradation rate * tyre_age [s].
 131
 132        Parameters
 133        ----------
 134        tyre_age : float or array_like
 135            Tyre age(s) [laps], finite and >= 0.
 136
 137        Returns
 138        -------
 139        numpy.ndarray
 140            Degradation [s], one value per age (1-D).
 141
 142        Raises
 143        ------
 144        ValueError
 145            For negative, NaN or infinite ages.
 146
 147        Example
 148        -------
 149        >>> LinearDegradation(0.05).degradation([0.0, 20.0]).tolist()
 150        [0.0, 1.0]
 151        """
 152        # Ages must be finite and non-negative; degradation grows linearly with age.
 153        ages = np.asarray(tyre_age, dtype=float).reshape(-1)
 154        if not np.all(np.isfinite(ages)) or np.any(ages < 0):
 155            raise ValueError("tyre_age must contain finite values >= 0 [laps].")
 156        return self.rate * ages

 159def _check_int(value, name, minimum):
 160    # Reject non-integers (and booleans), then enforce the lower bound.

 168def _check_race_inputs(models, total_laps, pit_loss, k_fuel):
 169    # Shared checks: compound models, race length >= 2, positive pit loss, k_fuel >= 0.
 170    if not isinstance(models, dict) or not models:
 171        raise TypeError("models must be a non-empty dict {compound: CompoundModel}.")
 172    total_laps = _check_int(total_laps, "total_laps", 2)
 173    if isinstance(pit_loss, bool) or not np.isfinite(pit_loss) or pit_loss <= 0:
 174        raise ValueError(f"pit_loss must be a positive number of seconds, got {pit_loss!r}.")
 175    if isinstance(k_fuel, bool) or not np.isfinite(k_fuel) or k_fuel < 0:
 176        raise ValueError(f"k_fuel must be a number >= 0, got {k_fuel!r}.")
 177    return total_laps

 195def stint_time(compound_model, n_laps):
 196    """Sum of predicted fuel-corrected lap times over a stint of ``n_laps`` new-tyre laps [s].
 197
 198    = n_laps * base + d(1) + d(2) + ... + d(n_laps)
 199
 200    Parameters
 201    ----------
 202    compound_model : CompoundModel
 203        The compound of the stint.
 204    n_laps : int
 205        Stint length [laps], >= 0 (0 gives 0 s).
 206
 207    Returns
 208    -------
 209    float
 210        Stint time [s], without the fuel effect.
 211
 212    Raises
 213    ------
 214    TypeError
 215        If ``compound_model`` is not a CompoundModel or ``n_laps`` is not an integer.
 216    ValueError
 217        If ``n_laps`` is negative.
 218
 219    Example
 220    -------
 221    >>> class Linear:
 222    ...     def degradation(self, n):
 223    ...         return 0.1 * np.asarray(n, dtype=float)
 224    >>> stint_time(CompoundModel("C3", Linear(), 80.0, 40), 3)   # 240 + 0.1 (1 + 2 + 3)
 225    240.6
 226    """
 227    # Check the inputs; an empty stint costs nothing.
 228    if not isinstance(compound_model, CompoundModel):
 229        raise TypeError(f"compound_model must be a CompoundModel, got {type(compound_model).__name__}.")
 230    n_laps = _check_int(n_laps, "n_laps", 0)
 231    if n_laps == 0:
 232        return 0.0
 233    # New tyres: the laps of the stint have tyre ages 1, 2, ..., n.
 234    ages = np.arange(1.0, n_laps + 1.0)
 235    # Stint time = n x base lap time + the degradation accumulated over those laps.
 236    return float(n_laps * compound_model.base_time + np.sum(compound_model.model.degradation(ages)))

 239def fuel_effect_total(total_laps, k_fuel):
 240    """Total time saved by burning fuel over the race: k_fuel N (N - 1) / 2 [s].
 241
 242    Lap n is k_fuel (n - 1) faster than lap 1, and the sum of (n - 1) over
 243    n = 1..N is N (N - 1) / 2.
 244
 245    Parameters
 246    ----------
 247    total_laps : int
 248        Race length N [laps], >= 1.
 249    k_fuel : float
 250        Fuel coefficient [s per lap of fuel], finite and >= 0.
 251
 252    Returns
 253    -------
 254    float
 255        Time saved [s], rounded to 12 decimals (removes round-off noise).
 256
 257    Raises
 258    ------
 259    TypeError
 260        If ``total_laps`` is not an integer.
 261    ValueError
 262        If ``total_laps`` < 1 or ``k_fuel`` is negative or not finite.
 263
 264    Example
 265    -------
 266    >>> fuel_effect_total(70, 0.046)   # 0.046 * 70 * 69 / 2
 267    111.09
 268    """
 269    # Check the inputs, then sum k_fuel x (n - 1) over all laps n = 1..N.
 270    total_laps = _check_int(total_laps, "total_laps", 1)
 271    if isinstance(k_fuel, bool) or not np.isfinite(k_fuel) or k_fuel < 0:
 272        raise ValueError(f"k_fuel must be a finite number >= 0, got {k_fuel!r}.")
 273    return float(round(k_fuel * total_laps * (total_laps - 1) / 2.0, 12))

 276def total_race_time(compounds, stint_lengths, models, pit_loss, k_fuel=0.0, add_fuel_effect=True,
 277                    enforce_max_stint=True):
 278    """Predicted race time for any number of stints [s].
 279
 280    Parameters
 281    ----------
 282    compounds : sequence of str
 283        Compound of each stint, at least two different ones (dry-race rule).
 284    stint_lengths : sequence of int
 285        Laps in each stint, each >= 1; their sum is the race length.
 286    models : dict
 287        {compound: CompoundModel}.
 288    pit_loss : float
 289        Time lost per pit stop [s], > 0.
 290    k_fuel : float, optional
 291        Fuel coefficient [s per lap of fuel], >= 0. Default 0.
 292    add_fuel_effect : bool, optional
 293        Subtract the fuel effect so the total is a real race time (D62).
 294    enforce_max_stint : bool, optional
 295        Raise if a stint exceeds its compound's ``max_stint_laps`` (D63).
 296
 297    Returns
 298    -------
 299    float
 300
 301    Raises
 302    ------
 303    TypeError, ValueError
 304        For invalid inputs, a single compound, or a stint that is too long.
 305
 306    Example
 307    -------
 308    >>> # see race_time for the one-stop case
 309    """
 310    # One compound per stint, at least two stints; the race length is the sum of the stints.
 311    if len(compounds) != len(stint_lengths) or len(compounds) < 2:
 312        raise ValueError("Need one compound per stint and at least two stints.")
 313    total_laps = int(np.sum([_check_int(n, "stint length", 1) for n in stint_lengths]))
 314    _check_race_inputs(models, total_laps, pit_loss, k_fuel)
 315    _check_compounds(compounds, models)
 316    # Add up each stint's time, refusing stints longer than the data support (no extrapolation).
 317    time = 0.0
 318    for compound, laps in zip(compounds, stint_lengths):
 319        if enforce_max_stint and laps > models[compound].max_stint_laps:
 320            raise ValueError(f"A {laps}-lap stint on {compound} exceeds its limit of "
 321                             f"{models[compound].max_stint_laps} laps (no extrapolation, D63).")
 322        time += stint_time(models[compound], laps)
 323    # One pit loss per stop (stints - 1 stops).
 324    time += pit_loss * (len(stint_lengths) - 1)
 325    # Corrected times are at full fuel; subtract the fuel saved to get the real race time.
 326    if add_fuel_effect:
 327        time -= fuel_effect_total(total_laps, k_fuel)
 328    return time

 331def race_time(pit_lap, compound_1, compound_2, models, total_laps, pit_loss, k_fuel=0.0,
 332              add_fuel_effect=True, enforce_max_stint=True):
 333    """Predicted time of a one-stop race [s].
 334
 335    Stint 1 runs laps 1..pit_lap on ``compound_1``; stint 2 runs the remaining
 336    ``total_laps - pit_lap`` laps on a new ``compound_2`` (tyre age resets).
 337
 338    Parameters
 339    ----------
 340    pit_lap : int
 341        Last lap of the first stint, 1 <= pit_lap < total_laps.
 342    compound_1, compound_2 : str
 343        Different compounds (dry-race rule).
 344    models : dict
 345        {compound: CompoundModel}.
 346    total_laps : int
 347        Race length [laps], >= 2.
 348    pit_loss : float
 349        Time lost by the stop [s], > 0.
 350    k_fuel : float, optional
 351        Fuel coefficient [s per lap of fuel], >= 0.
 352    add_fuel_effect : bool, optional
 353        Return a real race time (True, default) or a fuel-corrected one.
 354    enforce_max_stint : bool, optional
 355        Raise for stints longer than the compound's limit (default True).
 356
 357    Returns
 358    -------
 359    float
 360
 361    Raises
 362    ------
 363    TypeError
 364        For a non-integer pit lap or wrong types.
 365    ValueError
 366        If the compounds are equal or unknown, pit_lap is outside
 367        [1, total_laps - 1], pit_loss <= 0, or a stint is too long.
 368
 369    Example
 370    -------
 371    >>> class Linear:
 372    ...     def degradation(self, n):
 373    ...         return 0.1 * np.asarray(n, dtype=float)
 374    >>> models = {c: CompoundModel(c, Linear(), 80.0, 10) for c in ("C3", "C4")}
 375    >>> race_time(2, "C3", "C4", models, 4, pit_loss=20.0)   # 2 x (160 + 0.3) + 20
 376    340.6
 377    """
 378    # Check the inputs: the pit lap must leave laps for the second stint, on a different compound.
 379    total_laps = _check_race_inputs(models, total_laps, pit_loss, k_fuel)
 380    pit_lap = _check_int(pit_lap, "pit_lap", 1)
 381    if pit_lap >= total_laps:
 382        raise ValueError(f"pit_lap must be < total_laps ({total_laps}), got {pit_lap}.")
 383    if compound_1 == compound_2:
 384        raise ValueError(f"The two stints must use different compounds, got {compound_1} twice.")
 385    # A one-stop race is two stints: laps 1..pit_lap and the rest.
 386    return total_race_time((compound_1, compound_2), (pit_lap, total_laps - pit_lap), models,
 387                           pit_loss, k_fuel, add_fuel_effect, enforce_max_stint)

 393def _poly_antiderivative(coefficients, x):
 394    """D(x) = sum_k c_k x^(k+1) / (k+1) for d(x) = sum_k c_k x^k, k = 1..p."""
 395    # Integral of sum_k c_k x^k from 0 to x = sum_k c_k x^(k+1) / (k + 1).
 396    value = 0.0
 397    for power, coefficient in enumerate(coefficients, start=1):
 398        value += coefficient * x ** (power + 1) / (power + 1)
 399    return value

 402def _ode_antiderivative(a, b, x):
 403    """G(x) = integral_0^x a (exp(b s) - 1) / b ds = a (expm1(b x) - b x) / b^2.
 404
 405    For |b x| < 1e-4 the series a (x^2/2 + b x^3/6 + b^2 x^4/24) is used,
 406    because expm1(b x) - b x loses digits to cancellation there.
 407    """
 408    # For tiny b*x use the Taylor series, which avoids cancellation in expm1(bx) - bx.
 409    if abs(b * x) < 1e-4:
 410        return a * (x**2 / 2.0 + b * x**3 / 6.0 + b**2 * x**4 / 24.0)
 411    # Integral of a (e^(bx) - 1)/b from 0 to x.
 412    return a * (np.expm1(b * x) - b * x) / b**2

 415def cumulative_degradation(model, n_laps):
 416    """Smooth extension of d(1) + ... + d(n) to real n (for the continuous relaxation).
 417
 418    The sum is replaced by the integral of d from 1/2 to n + 1/2 (midpoint
 419    rule): integral_{j-1/2}^{j+1/2} d = d(j) exactly when d is linear, so for
 420    linear degradation the extension equals the sum at every integer n and
 421    is smooth in between. For curved d the difference is tiny (O(d'')).
 422
 423    Parameters
 424    ----------
 425    model : PolynomialDegradationModel or WearODEModel
 426        Fitted model with a closed-form antiderivative.
 427    n_laps : float
 428        Stint length [laps], >= 0 (need not be an integer).
 429
 430    Returns
 431    -------
 432    float
 433
 434    Raises
 435    ------
 436    TypeError
 437        For models without a closed-form integral (e.g. KNN): use brute force.
 438    ValueError
 439        If n_laps < 0.
 440
 441    Example
 442    -------
 443    >>> model = PolynomialDegradationModel("C3").fit([1, 2, 3], [80.1, 80.2, 80.3])
 444    >>> round(cumulative_degradation(model, 3.0), 9)   # 0.1 + 0.2 + 0.3
 445    0.6
 446    """
 447    # A stint of 0 laps has no degradation.
 448    if not n_laps >= 0:
 449        raise ValueError(f"n_laps must be >= 0, got {n_laps}.")
 450    if n_laps == 0:
 451        return 0.0
 452    # Midpoint rule: the sum d(1) + ... + d(n) is replaced by the integral from 0.5 to n + 0.5.
 453    upper, lower = n_laps + 0.5, 0.5
 454    # Use each model's closed-form integral; KNN has none.
 455    if isinstance(model, PolynomialDegradationModel):
 456        coefficients = model.params()["coefficients"]
 457        return float(_poly_antiderivative(coefficients, upper) - _poly_antiderivative(coefficients, lower))
 458    if isinstance(model, WearODEModel):
 459        p = model.params()
 460        return float(_ode_antiderivative(p["a"], p["b"], upper) - _ode_antiderivative(p["a"], p["b"], lower))
 461    if isinstance(model, LinearDegradation):
 462        return float(_poly_antiderivative([model.rate], upper) - _poly_antiderivative([model.rate], lower))
 463    raise TypeError(
 464        f"{type(model).__name__} has no closed-form integral; use the brute-force optimiser."
 465    )

 468def race_time_continuous(pit_lap, compound_1, compound_2, models, total_laps, pit_loss, k_fuel=0.0,
 469                         add_fuel_effect=True):
 470    """One-stop race time for a REAL-valued pit lap L (the continuous relaxation).
 471
 472    Same as :func:`race_time` with each stint's sum of degradation replaced by
 473    :func:`cumulative_degradation`; equal to it at integer L for linear models.
 474    Stint limits are not applied here (they are applied after rounding).
 475
 476    Parameters
 477    ----------
 478    pit_lap : float
 479        Real-valued pit lap L, 0 < L < total_laps.
 480    compound_1, compound_2 : str
 481        Compounds of stint 1 and stint 2; different and both in ``models``.
 482    models : dict
 483        {compound: CompoundModel}.
 484    total_laps : int
 485        Race length [laps], >= 2.
 486    pit_loss : float
 487        Time lost by the stop [s], > 0.
 488    k_fuel : float, optional
 489        Fuel coefficient [s per lap of fuel], >= 0. Default 0.
 490    add_fuel_effect : bool, optional
 491        Real race time (True, default) or a fuel-corrected one.
 492
 493    Returns
 494    -------
 495    float
 496        Relaxed race time [s].
 497
 498    Raises
 499    ------
 500    ValueError
 501        If L is outside (0, total_laps) or the compounds are invalid.
 502    TypeError
 503        For models without a closed-form integral.
 504
 505    Example
 506    -------
 507    >>> models = {"C3": CompoundModel("C3", LinearDegradation(0.06), 85.0, 40),
 508    ...           "C4": CompoundModel("C4", LinearDegradation(0.055), 84.9, 35)}
 509    >>> round(race_time_continuous(32.5, "C3", "C4", models, 70, 20.9, 0.046), 6)
 510    5928.425625
 511    """
 512    # Check the inputs; the pit lap may be any real number inside the race.
 513    total_laps = _check_race_inputs(models, total_laps, pit_loss, k_fuel)
 514    _check_compounds((compound_1, compound_2), models)
 515    if not 0 < pit_lap < total_laps:
 516        raise ValueError(f"pit_lap must lie in (0, {total_laps}), got {pit_lap}.")
 517    # Same as the integer race time, but the stint sums are smooth integrals of d.
 518    first, second = models[compound_1], models[compound_2]
 519    second_laps = total_laps - pit_lap
 520    time = (pit_lap * first.base_time + cumulative_degradation(first.model, pit_lap)
 521            + second_laps * second.base_time + cumulative_degradation(second.model, second_laps)
 522            + pit_loss)
 523    # Subtract the fuel saved, as in the integer race time.
 524    if add_fuel_effect:
 525        time -= fuel_effect_total(total_laps, k_fuel)
 526    return time

 582def feasible_pit_laps(compound_1, compound_2, models, total_laps):
 583    """Integer pit laps for which both stints respect their limits (D63).
 584
 585    Parameters
 586    ----------
 587    compound_1, compound_2 : str
 588        Compounds of stint 1 and stint 2, both in ``models``.
 589    models : dict
 590        {compound: CompoundModel}.
 591    total_laps : int
 592        Race length [laps], >= 2.
 593
 594    Returns
 595    -------
 596    numpy.ndarray of int
 597        Possibly empty if no one-stop race is feasible.
 598
 599    Raises
 600    ------
 601    TypeError
 602        If ``models`` is not a non-empty dict or ``total_laps`` is not an integer.
 603    ValueError
 604        If a compound is unknown or ``total_laps`` < 2.
 605
 606    Example
 607    -------
 608    >>> class Zero:
 609    ...     def degradation(self, n):
 610    ...         return np.zeros(np.size(n))
 611    >>> models = {"C3": CompoundModel("C3", Zero(), 80.0, 40), "C4": CompoundModel("C4", Zero(), 80.0, 35)}
 612    >>> feasible_pit_laps("C3", "C4", models, 70).tolist()   # C3 <= 40 laps, C4 <= 35 laps
 613    [35, 36, 37, 38, 39, 40]
 614    """
 615    # Validate the models, race length and compounds.
 616    if not isinstance(models, dict) or not models:
 617        raise TypeError("models must be a non-empty dict {compound: CompoundModel}.")
 618    total_laps = _check_int(total_laps, "total_laps", 2)
 619    for compound in (compound_1, compound_2):
 620        if compound not in models:
 621            raise ValueError(f"Unknown compound {compound!r}; available: {sorted(models)}.")
 622    # Earliest pit lap: the second stint must fit its limit. Latest: the first stint must fit its
 623    # own.
 624    low = max(1, total_laps - models[compound_2].max_stint_laps)
 625    high = min(total_laps - 1, models[compound_1].max_stint_laps)
 626    return np.arange(low, high + 1)

 629def optimise_brute_force(compound_1, compound_2, models, total_laps, pit_loss, k_fuel=0.0,
 630                         add_fuel_effect=True):
 631    """Try every feasible integer pit lap; return the fastest (the reference method).
 632
 633    Parameters
 634    ----------
 635    compound_1, compound_2 : str
 636        Compounds of stint 1 and stint 2; different and both in ``models``.
 637    models : dict
 638        {compound: CompoundModel}.
 639    total_laps : int
 640        Race length [laps], >= 2.
 641    pit_loss : float
 642        Time lost by the stop [s], > 0.
 643    k_fuel : float, optional
 644        Fuel coefficient [s per lap of fuel], >= 0. Default 0.
 645    add_fuel_effect : bool, optional
 646        Real race time (True, default) or a fuel-corrected one.
 647
 648    Returns
 649    -------
 650    StrategyResult
 651        ``method == "brute force"``; ``iterations`` = number of candidates.
 652
 653    Raises
 654    ------
 655    ValueError
 656        If no pit lap is feasible, or for invalid inputs (see :func:`race_time`).
 657
 658    Example
 659    -------
 660    >>> models = {"C3": CompoundModel("C3", LinearDegradation(0.06), 85.0, 40),
 661    ...           "C4": CompoundModel("C4", LinearDegradation(0.055), 84.9, 35)}
 662    >>> result = optimise_brute_force("C3", "C4", models, 70, 20.9, 0.046)
 663    >>> result.pit_laps, round(result.total_time, 6), result.iterations
 664    ((35,), 5928.76, 6)
 665    """
 666    # Check the inputs and list every pit lap that respects both stint limits.
 667    total_laps = _check_race_inputs(models, total_laps, pit_loss, k_fuel)
 668    _check_compounds((compound_1, compound_2), models)
 669    candidates = feasible_pit_laps(compound_1, compound_2, models, total_laps)
 670    if candidates.size == 0:
 671        raise ValueError(f"No feasible one-stop race {compound_1}->{compound_2} within the stint limits.")
 672    # Evaluate the exact race time at every candidate and keep the fastest (the reference method).
 673    times = [race_time(int(lap), compound_1, compound_2, models, total_laps, pit_loss, k_fuel,
 674                       add_fuel_effect) for lap in candidates]
 675    best = int(np.argmin(times))
 676    pit_lap = int(candidates[best])
 677    return StrategyResult(
 678        compounds=(compound_1, compound_2), method="brute force", pit_laps=(pit_lap,),
 679        total_time=float(times[best]), stint_lengths=(pit_lap, total_laps - pit_lap),
 680        iterations=int(candidates.size), nfev=int(candidates.size),
 681        extra={"times": dict(zip(candidates.tolist(), times))},
 682    )

 685def optimise_continuous(compound_1, compound_2, models, total_laps, pit_loss, k_fuel=0.0,
 686                        add_fuel_effect=True, root_finder="secant", xtol=1e-6, ftol=0.0):
 687    """Continuous relaxation: solve dT/dL = 0, then round and check neighbours (D64).
 688
 689    Steps:
 690
 691    1. dT/dL is computed with my central difference of
 692       :func:`race_time_continuous`.
 693    2. Its root is found with my secant method (started at the two ends of
 694       the feasible window) or Newton's method (started at the window
 695       centre, with my central second difference as the derivative).
 696    3. Candidates floor(root) - 1 ... ceil(root) + 1 are clipped into the
 697       feasible window and evaluated with the exact integer
 698       :func:`race_time`; the fastest wins. If the root lies outside the
 699       window, the nearest window end wins and ``constraint_active`` is set.
 700       If the root finder fails (e.g. a flat or non-convex race time), both
 701       window ends are evaluated instead and a note is recorded.
 702
 703    Parameters
 704    ----------
 705    compound_1, compound_2, models, total_laps, pit_loss, k_fuel, add_fuel_effect
 706        As for :func:`race_time`.
 707    root_finder : str, optional
 708        "secant" (default) or "newton".
 709    xtol, ftol : float, optional
 710        Root-finding tolerances (D64: 1e-6 laps, residual test off).
 711
 712    Returns
 713    -------
 714    StrategyResult
 715
 716    Raises
 717    ------
 718    ValueError
 719        For invalid inputs, an unknown root finder, or no feasible pit lap.
 720    TypeError
 721        For models without a closed-form integral (KNN).
 722
 723    Example
 724    -------
 725    >>> optimise_continuous("C3", "C4", models, 70, 20.9, 0.046, root_finder="newton")  # doctest: +SKIP
 726    """
 727    # Check the inputs and find the feasible pit-lap window.
 728    if root_finder not in VALID_ROOT_FINDERS:
 729        raise ValueError(f"root_finder must be one of {VALID_ROOT_FINDERS}, got {root_finder!r}.")
 730    total_laps = _check_race_inputs(models, total_laps, pit_loss, k_fuel)
 731    _check_compounds((compound_1, compound_2), models)
 732    window = feasible_pit_laps(compound_1, compound_2, models, total_laps)
 733    if window.size == 0:
 734        raise ValueError(f"No feasible one-stop race {compound_1}->{compound_2} within the stint limits.")
 735    # Count evaluations of the smooth and the exact race time separately.
 736    calls = {"continuous": 0, "integer": 0}
 737
 738    # The relaxed race time T(L) with a real pit lap L.
 739    def relaxed(pit_lap):
 740        calls["continuous"] += 1
 741        return race_time_continuous(pit_lap, compound_1, compound_2, models, total_laps, pit_loss,
 742                                    k_fuel, add_fuel_effect)
 743
 744    # Its slope dT/dL by central difference; the optimum is where the slope is zero.
 745    def slope(pit_lap):
 746        return central_difference(relaxed, pit_lap)
 747
 748    # Find the root of the slope with the chosen root finder.
 749    note, root, iterations = "", None, 0
 750    try:
 751        # Secant starts from the two ends of the window (widened if the window is a single lap).
 752        if root_finder == "secant":
 753            low, high = float(window[0]), float(window[-1])
 754            if low == high:
 755                low, high = max(0.5, low - 1.0), min(total_laps - 0.5, high + 1.0)
 756            result = secant(slope, low, high, xtol=xtol, ftol=ftol,
 757                            divergence_limit=float(total_laps))
 758        else:
 759            # Newton uses the second difference as the derivative of the slope, starting mid-
 760            # window.
 761            result = newton(slope, lambda x: central_second_difference(relaxed, x),
 762                            float(window[0] + window[-1]) / 2.0, xtol=xtol, ftol=ftol,
 763                            divergence_limit=float(total_laps))
 764        root, iterations = float(result.root), result.iterations
 765    # If root finding fails, fall back to comparing the two ends of the window.
 766    except (ZeroDerivativeError, DivergenceError, NotConvergedError, ValueError) as error:
 767        note = f"root finding failed ({type(error).__name__}); window ends compared instead"
 768
 769    # Candidates: the window ends if no usable root, else the integers around the root, kept in the
 770    # window.
 771    if root is None or not 0 < root < total_laps:
 772        candidates = {int(window[0]), int(window[-1])}
 773    else:
 774        nearby = range(int(np.floor(root)) - 1, int(np.ceil(root)) + 2)
 775        candidates = {int(np.clip(lap, window[0], window[-1])) for lap in nearby}
 776
 777    # Exact integer race time, counted separately.
 778    def exact(lap):
 779        calls["integer"] += 1
 780        return race_time(lap, compound_1, compound_2, models, total_laps, pit_loss, k_fuel,
 781                         add_fuel_effect)
 782
 783    # Evaluate the candidates exactly and keep the fastest.
 784    times = {lap: exact(lap) for lap in sorted(candidates)}
 785    pit_lap = min(times, key=times.get)
 786    # The stint limits are active if the relaxed optimum lies outside the feasible window.
 787    constraint_active = root is not None and not window[0] - 0.5 <= root <= window[-1] + 0.5
 788    return StrategyResult(
 789        compounds=(compound_1, compound_2), method=root_finder, pit_laps=(pit_lap,),
 790        total_time=float(times[pit_lap]), stint_lengths=(pit_lap, total_laps - pit_lap),
 791        iterations=iterations, nfev=calls["continuous"] + calls["integer"],
 792        continuous_root=root, constraint_active=bool(constraint_active), note=note,
 793        extra={"nfev_continuous": calls["continuous"], "nfev_integer": calls["integer"]},
 794    )

 797def optimise_two_stop(compounds, models, total_laps, pit_loss, k_fuel=0.0, add_fuel_effect=True):
 798    """Brute force over every pair of pit laps for a three-stint sequence.
 799
 800    Parameters
 801    ----------
 802    compounds : sequence of 3 str
 803        Compound of each stint; at least two different ones.
 804    models, total_laps, pit_loss, k_fuel, add_fuel_effect
 805        As for :func:`race_time`.
 806
 807    Returns
 808    -------
 809    StrategyResult
 810        ``pit_laps`` = (first stop, second stop).
 811
 812    Raises
 813    ------
 814    ValueError
 815        For invalid inputs or no feasible combination.
 816
 817    Example
 818    -------
 819    >>> optimise_two_stop(("C3", "C4", "C3"), models, 70, 20.9, 0.046)  # doctest: +SKIP
 820    """
 821    # Three stints with valid compounds and race inputs.
 822    if len(compounds) != 3:
 823        raise ValueError("A two-stop race has exactly three stints.")
 824    total_laps = _check_race_inputs(models, total_laps, pit_loss, k_fuel)
 825    _check_compounds(compounds, models)
 826    # Stint sums for every possible stint length, computed once per compound.
 827    # Precompute every stint time once per compound, so each combination is just three lookups.
 828    sums = {c: [stint_time(models[c], n) for n in range(total_laps + 1)] for c in set(compounds)}
 829    limits = [models[c].max_stint_laps for c in compounds]
 830    best, evaluations = None, 0
 831    # Try every split into three stints that respects all three stint limits.
 832    for first in range(1, min(limits[0], total_laps - 2) + 1):
 833        for second in range(1, min(limits[1], total_laps - first - 1) + 1):
 834            third = total_laps - first - second
 835            if third > limits[2]:
 836                continue
 837            evaluations += 1
 838            time = sums[compounds[0]][first] + sums[compounds[1]][second] + sums[compounds[2]][third]
 839            if best is None or time < best[0]:
 840                best = (time, first, second, third)
 841    # No combination fits the limits.
 842    if best is None:
 843        raise ValueError(f"No feasible two-stop race {'->'.join(compounds)} within the stint limits.")
 844    # Add the two pit losses and subtract the fuel saved.
 845    time, first, second, third = best
 846    time += 2 * pit_loss
 847    if add_fuel_effect:
 848        time -= fuel_effect_total(total_laps, k_fuel)
 849    return StrategyResult(
 850        compounds=tuple(compounds), method="brute force", pit_laps=(first, first + second),
 851        total_time=float(time), stint_lengths=(first, second, third), iterations=evaluations,
 852        nfev=evaluations,
 853    )

 856def compare_strategies(models, total_laps, pit_loss, k_fuel=0.0, add_fuel_effect=True,
 857                       include_two_stop=True, xtol=1e-6, ftol=0.0):
 858    """Optimise every one-stop compound order (all methods) and, optionally, two-stop sequences.
 859
 860    Parameters
 861    ----------
 862    models : dict
 863        {compound: CompoundModel}; at least two compounds.
 864    total_laps : int
 865        Race length [laps], >= 2.
 866    pit_loss : float
 867        Time lost per stop [s], > 0.
 868    k_fuel : float, optional
 869        Fuel coefficient [s per lap of fuel], >= 0. Default 0.
 870    add_fuel_effect : bool, optional
 871        Real race times (True, default) or fuel-corrected ones.
 872    include_two_stop : bool, optional
 873        Also enumerate two-stop sequences (default True).
 874    xtol, ftol : float, optional
 875        Root-finder tolerances for the continuous methods [laps], >= 0.
 876
 877    Returns
 878    -------
 879    methods : pandas.DataFrame
 880        One row per (one-stop strategy, method): optimum, time, iterations, nfev.
 881    ranking : pandas.DataFrame
 882        One row per strategy (best result), sorted fastest first, with the
 883        gap to the fastest [s].
 884
 885    Raises
 886    ------
 887    TypeError, ValueError
 888        For invalid models, race length, pit loss or fuel coefficient
 889        (see :func:`race_time`).
 890
 891    Example
 892    -------
 893    >>> models = {"C3": CompoundModel("C3", LinearDegradation(0.06), 85.0, 40),
 894    ...           "C4": CompoundModel("C4", LinearDegradation(0.055), 84.9, 35)}
 895    >>> methods, ranking = compare_strategies(models, 70, 20.9, 0.046)
 896    >>> ranking[["strategy", "pit_laps"]].head(2).values.tolist()
 897    [['C3 -> C4 -> C4', '21 & 45'], ['C4 -> C4 -> C3', '24 & 49']]
 898    """
 899    # Every one-stop order, solved by brute force and by both continuous methods where possible.
 900    rows = []
 901    compounds = sorted(models)
 902    for first, second in itertools.permutations(compounds, 2):
 903        results = [optimise_brute_force(first, second, models, total_laps, pit_loss, k_fuel, add_fuel_effect)]
 904        for finder in VALID_ROOT_FINDERS:
 905            try:
 906                results.append(optimise_continuous(first, second, models, total_laps, pit_loss, k_fuel,
 907                                                   add_fuel_effect, finder, xtol, ftol))
 908            except TypeError:
 909                pass  # no closed-form integral (KNN): brute force only
 910        rows += [_result_row(result, "1-stop") for result in results]
 911    # Every three-stint sequence that uses at least two compounds.
 912    if include_two_stop:
 913        for sequence in itertools.product(compounds, repeat=3):
 914            if len(set(sequence)) < 2:
 915                continue
 916            try:
 917                result = optimise_two_stop(sequence, models, total_laps, pit_loss, k_fuel, add_fuel_effect)
 918            except ValueError:
 919                continue  # no feasible combination within the stint limits
 920            rows.append(_result_row(result, "2-stop"))
 921    # One row per strategy and method; the ranking keeps each strategy's best time, fastest first.
 922    methods = pd.DataFrame(rows)
 923    ranking = methods.loc[methods.groupby("strategy")["total_time"].idxmin()]
 924    ranking = ranking.sort_values("total_time").reset_index(drop=True)
 925    ranking["gap_to_best_s"] = ranking["total_time"] - ranking["total_time"].iloc[0]
 926    ranking.insert(0, "rank", np.arange(1, len(ranking) + 1))
 927    return methods, ranking

 945def max_stint_from_data(tyre_age, min_laps):
 946    """Largest tyre age [laps] with at least ``min_laps`` clean laps (D63).
 947
 948    Parameters
 949    ----------
 950    tyre_age : array_like of float
 951        Tyre age [laps] of every clean lap of one compound, finite and >= 0.
 952    min_laps : int
 953        Minimum number of laps observed at an age, >= 1 (config: 5).
 954
 955    Returns
 956    -------
 957    int
 958        The stint limit [laps] (largest supported age, rounded down).
 959
 960    Raises
 961    ------
 962    TypeError
 963        If ``min_laps`` is not an integer.
 964    ValueError
 965        If ``tyre_age`` is empty or invalid, ``min_laps`` < 1, or no age has
 966        ``min_laps`` laps.
 967
 968    Example
 969    -------
 970    >>> max_stint_from_data([1, 1, 2, 2, 3], min_laps=2)
 971    2
 972    """
 973    # Validate the ages and the minimum lap count.
 974    ages = np.asarray(tyre_age, dtype=float).reshape(-1)
 975    if ages.size == 0 or not np.all(np.isfinite(ages)) or np.any(ages < 0):
 976        raise ValueError("tyre_age must be a non-empty array of finite ages >= 0 [laps].")
 977    _check_int(min_laps, "min_laps", 1)
 978    # Count the laps at each tyre age and keep the ages seen at least min_laps times.
 979    values, counts = np.unique(ages, return_counts=True)
 980    supported = values[counts >= min_laps]
 981    if supported.size == 0:
 982        raise ValueError(f"No tyre age has {min_laps} or more laps.")
 983    # The stint limit is the oldest such age.
 984    return int(np.floor(supported.max()))

 987def compound_pace_delta(offsets, reference, other):
 988    """Order-balanced pace difference other - reference for the same car [s] (D60).
 989
 990    For each driver-race that used both compounds, the difference of their
 991    stint offsets is taken. These differences depend strongly on which
 992    compound ran FIRST (a later stint looks faster, CHALLENGES.md C2), so the
 993    median is taken separately for each order and the two medians are
 994    averaged: a common order effect e then cancels, since
 995    ((delta - e) + (delta + e)) / 2 = delta.
 996
 997    Parameters
 998    ----------
 999    offsets : pandas.DataFrame
1000        Columns race, driver, stint (int), compound, offset [s] (one row per stint).
1001    reference, other : str
1002        The two compounds.
1003
1004    Returns
1005    -------
1006    dict
1007        delta (order-balanced), median_other_first, median_reference_first,
1008        n_other_first, n_reference_first.
1009
1010    Raises
1011    ------
1012    ValueError
1013        If either order has no driver-race.
1014
1015    Example
1016    -------
1017    >>> df = pd.DataFrame({"race": ["r"] * 4, "driver": ["A", "A", "B", "B"], "stint": [1, 2, 1, 2],
1018    ...                    "compound": ["C4", "C3", "C3", "C4"], "offset": [80.3, 80.0, 80.4, 80.0]})
1019    >>> compound_pace_delta(df, "C3", "C4")["delta"]   # orders: +0.3 and -0.4 -> -0.05
1020    -0.05
1021    """
1022    # Compare the two compounds within the same driver and race (same car), split by stint order.
1023    differences = {"other_first": [], "reference_first": []}
1024    for _, group in offsets.groupby(["race", "driver"]):
1025        ref = group[group["compound"] == reference]
1026        oth = group[group["compound"] == other]
1027        if ref.empty or oth.empty:
1028            continue
1029        # The first stint of each compound represents it for this driver-race.
1030        # Use each compound's first stint and record which compound ran first.
1031        ref_row = ref.sort_values("stint").iloc[0]
1032        oth_row = oth.sort_values("stint").iloc[0]
1033        key = "other_first" if oth_row["stint"] < ref_row["stint"] else "reference_first"
1034        differences[key].append(oth_row["offset"] - ref_row["offset"])
1035    # Both orders are needed, because each order alone is biased (fuel load, track evolution).
1036    if not differences["other_first"] or not differences["reference_first"]:
1037        raise ValueError("Both stint orders are needed for the order-balanced estimate.")
1038    # Average the medians of the two orders so the order effect cancels.
