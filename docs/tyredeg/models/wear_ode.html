tyredeg.models.wear_ode

Wear-ODE tyre-degradation model.

lap_time = offset_of_its_stint + d(n),   dd/dn = a + b d,   d(0) = 0

a [s/lap] is the initial wear rate and b [1/lap] how the rate changes as the tyre degrades: b > 0 accelerates towards a "cliff", b = 0 is linear wear (d = a n), b < 0 levels off. Exact solution:

d(n) = (a / b) (exp(b n) - 1)     (b != 0),      d(n) = a n   (b = 0)

How the fit works (DECISIONS.md D41, D42)

  1. Linearity in a: the ODE is linear, so d(n) = a * g_b(n) where the "unit response" g_b solves dg/dn = 1 + b g, g(0) = 0. g_b is computed ONCE per b with my RK4 (default, 1-lap steps), my RK45, or the exact formula.
  2. For fixed b the model is linear in (stint offsets, a): a comes from my linear least squares on the within-stint transformed data (Frisch-Waugh- Lovell, see tyredeg.models.common). This gives the profile RSS(b) = min over (offsets, a) of the residual sum of squares.
  3. b minimises RSS(b) on the bracket [-0.1, 0.1]: RSS is first evaluated on a 21-point grid to find the lowest point, then dRSS/db = 0 is solved between its grid neighbours by my root finder (bisection by default), with dRSS/db from my central difference. Because that derivative has round-off noise of about 1e-8, the root finder uses xtol = 1e-8 and no residual test.
  4. Constraint (D43): for n > 0, g_b(n) > 0 for every b, so d >= 0 exactly when a >= 0. If least squares gives a < 0 for some b, the constrained optimum for that b is a = 0 (a one-variable quadratic), which is used and flagged.

 69def _check_b(b):
 70    if isinstance(b, bool) or not np.isfinite(np.asarray(b, dtype=float)).all():
 71        raise ValueError(f"b must be a finite number, got {b!r}.")
 72    return float(b)

 75def exact_unit_response(tyre_age, b):
 76    """Exact g_b(n) = (exp(b n) - 1) / b, with the limit g_0(n) = n.
 77
 78    ``numpy.expm1(x)`` computes exp(x) - 1 accurately even for tiny x, where
 79    the textbook form loses digits to cancellation (exp(1e-12) - 1 keeps only
 80    ~4 correct digits). So the b -> 0 limit needs no special series: only
 81    b == 0 itself is handled separately, to avoid 0 / 0.
 82
 83    Parameters
 84    ----------
 85    tyre_age : float or array_like
 86        Tyre age(s) n [laps], >= 0.
 87    b : float
 88        Wear-acceleration parameter [1/lap], finite.
 89
 90    Returns
 91    -------
 92    numpy.ndarray
 93        g_b(n) [laps].
 94
 95    Raises
 96    ------
 97    ValueError
 98        For negative/NaN ages or a non-finite b.
 99
100    Example
101    -------
102    >>> exact_unit_response([10.0], 0.0).tolist(), exact_unit_response([10.0], 1e-12).round(9).tolist()
103    ([10.0], [10.0])
104    """
105    age = check_tyre_age(tyre_age)
106    b = _check_b(b)
107    if b == 0.0:
108        return age.copy()
109    return np.expm1(b * age) / b

112def exact_degradation(tyre_age, a, b):
113    """Exact d(n) = a * g_b(n) [s] for the wear ODE.
114
115    Parameters
116    ----------
117    tyre_age : float or array_like
118        Tyre age(s) [laps], >= 0.
119    a : float
120        Initial wear rate [s/lap].
121    b : float
122        Wear-acceleration parameter [1/lap].
123
124    Returns
125    -------
126    numpy.ndarray
127
128    Raises
129    ------
130    ValueError
131        For invalid inputs.
132
133    Example
134    -------
135    >>> exact_degradation([40.0], 0.05, 0.0).tolist()
136    [2.0]
137    """
138    a = float(a)
139    if not np.isfinite(a):
140        raise ValueError(f"a must be finite, got {a!r}.")
141    return a * exact_unit_response(tyre_age, b)

144def unit_response(tyre_age, b, solver=DEFAULT_SOLVER, rk4_step=DEFAULT_RK4_STEP,
145                  rk45_rtol=DEFAULT_RK45_RTOL, rk45_atol=DEFAULT_RK45_ATOL):
146    """g_b(n) at the given tyre ages, from dg/dn = 1 + b g, g(0) = 0.
147
148    Parameters
149    ----------
150    tyre_age : float or array_like
151        Tyre ages [laps], >= 0. For "rk4" every age must be a multiple of
152        ``rk4_step`` (whole laps with the default step of 1 lap).
153    b : float
154        Wear-acceleration parameter [1/lap].
155    solver : str, optional
156        "rk4" (default), "rk45" or "exact".
157    rk4_step : float, optional
158        RK4 step [laps], > 0. Default 1.0 (D42).
159    rk45_rtol, rk45_atol : float, optional
160        RK45 tolerances. Defaults 1e-10 / 1e-12 (tight, so RSS(b) is smooth
161        enough for the central-difference derivative, D42).
162
163    Returns
164    -------
165    numpy.ndarray
166        g_b at each input age (same order).
167
168    Raises
169    ------
170    ValueError
171        For invalid ages/b/solver, or ages that are not on the RK4 grid.
172
173    Example
174    -------
175    >>> unit_response([0.0, 1.0, 2.0], 0.0).round(12).tolist()
176    [0.0, 1.0, 2.0]
177    """
178    age = check_tyre_age(tyre_age)
179    b = _check_b(b)
180    if solver not in VALID_SOLVERS:
181        raise ValueError(f"solver must be one of {VALID_SOLVERS}, got {solver!r}.")
182    if solver == "exact":
183        return exact_unit_response(age, b)
184
185    def rhs(n, g):
186        return 1.0 + b * g
187
188    unique_ages = np.unique(age)
189    values = np.zeros(unique_ages.size)
190    max_age = unique_ages[-1]
191    if max_age == 0.0:
192        return np.zeros_like(age)
193
194    if solver == "rk4":
195        if not rk4_step > 0:
196            raise ValueError(f"rk4_step must be > 0, got {rk4_step}.")
197        positions = unique_ages / rk4_step
198        if not np.allclose(positions, np.round(positions), atol=1e-9):
199            raise ValueError("With solver 'rk4' every tyre age must be a multiple of rk4_step.")
200        if max_age < rk4_step:
201            raise ValueError("The largest tyre age is smaller than rk4_step.")
202        times, g, _ = rk4(rhs, (0.0, max_age), 0.0, rk4_step)
203        grid_index = np.round(times / rk4_step).astype(int)
204        lookup = dict(zip(grid_index, g))
205        values = np.array([lookup[int(round(p))] for p in positions])
206    else:
207        # My RK45 returns only its own accepted points, so integrate from one
208        # required age to the next and keep the end value of each segment.
209        current_age, current_g = 0.0, 0.0
210        for i, target in enumerate(unique_ages):
211            if target > current_age:
212                _, g, _, _ = rk45(rhs, (current_age, target), current_g,
213                                  rtol=rk45_rtol, atol=rk45_atol)
214                current_age, current_g = target, float(g[-1])
215            values[i] = current_g
216    return values[np.searchsorted(unique_ages, age)]

222class WearODEModel:
223    """Wear-ODE degradation model d(n) = a g_b(n) with per-stint offsets.
224
225    Parameters
226    ----------
227    compound : str
228        Pirelli compound code, e.g. "C3".
229    solver : str, optional
230        ODE solver for g_b: "rk4" (default), "rk45" or "exact".
231    b_bracket : tuple of float, optional
232        Search interval for b [1/lap], low < high. Default (-0.1, 0.1).
233    b_grid_points : int, optional
234        Grid points for the initial RSS scan, >= 3. Default 21.
235    b_xtol, b_ftol : float, optional
236        Root-finding tolerances for dRSS/db = 0. Defaults 1e-8 and 0 (D41).
237    root_finder : str, optional
238        "bisection" (default), "secant" or "newton".
239    rk4_step, rk45_rtol, rk45_atol : float, optional
240        Solver settings (see :func:`unit_response`).
241    negative_tolerance_s : float, optional
242        Degradation below -tolerance [s] is flagged. Default 0.01.
243
244    Raises
245    ------
246    TypeError, ValueError
247        For invalid settings or an unknown compound.
248
249    Example
250    -------
251    >>> ages = np.tile(np.arange(1.0, 31.0), 2)
252    >>> times = 80.0 + exact_degradation(ages, 0.05, 0.03)
253    >>> model = WearODEModel("C3").fit(ages, times, stint_id=[0] * 30 + [1] * 30)
254    >>> p = model.params()
255    >>> round(p["a"], 4), round(p["b"], 4)
256    (0.05, 0.03)
257    """
258
259    def __init__(self, compound, solver=DEFAULT_SOLVER, b_bracket=DEFAULT_B_BRACKET,
260                 b_grid_points=DEFAULT_B_GRID_POINTS, b_xtol=DEFAULT_B_XTOL,
261                 b_ftol=DEFAULT_B_FTOL, root_finder="bisection", rk4_step=DEFAULT_RK4_STEP,
262                 rk45_rtol=DEFAULT_RK45_RTOL, rk45_atol=DEFAULT_RK45_ATOL,
263                 negative_tolerance_s=DEFAULT_NEGATIVE_TOLERANCE_S):
264        self.compound = check_compound(compound)
265        if solver not in VALID_SOLVERS:
266            raise ValueError(f"solver must be one of {VALID_SOLVERS}, got {solver!r}.")
267        if root_finder not in VALID_ROOT_FINDERS:
268            raise ValueError(f"root_finder must be one of {VALID_ROOT_FINDERS}, got {root_finder!r}.")
269        low, high = (float(value) for value in b_bracket)
270        if not (np.isfinite(low) and np.isfinite(high) and low < high):
271            raise ValueError(f"b_bracket must be finite with low < high, got {b_bracket!r}.")
272        if isinstance(b_grid_points, bool) or not isinstance(b_grid_points, (int, np.integer)) \
273                or b_grid_points < 3:
274            raise ValueError(f"b_grid_points must be an integer >= 3, got {b_grid_points!r}.")
275        if not negative_tolerance_s >= 0:
276            raise ValueError("negative_tolerance_s must be >= 0.")
277        self.solver = solver
278        self.b_bracket = (low, high)
279        self.b_grid_points = int(b_grid_points)
280        self.b_xtol = b_xtol
281        self.b_ftol = b_ftol
282        self.root_finder = root_finder
283        self.rk4_step = rk4_step
284        self.rk45_rtol = rk45_rtol
285        self.rk45_atol = rk45_atol
286        self.negative_tolerance_s = float(negative_tolerance_s)
287        self._fitted = False
288        self.bootstrap_result = None

297    def _profile(self, data, within_y, b):
298        """Best a for fixed b and the resulting RSS: returns (rss, a, a_was_clamped)."""
299        within_g = data.demean(self._unit_response(data.tyre_age, b))
300        if not np.any(within_g != 0):
301            raise ValueError("Tyre age does not vary within any stint; a and b cannot be fitted.")
302        result = fit_linear_least_squares(within_g.reshape(-1, 1), within_y)
303        a = float(result.coefficients[0])
304        if a < 0:
305            # Constrained optimum for this b is a = 0: the model then predicts
306            # only the stint means, so the residuals are within_y itself.
307            return float(within_y @ within_y), 0.0, True
308        return result.residual_sum_of_squares, a, False
309
310    def _search_b(self, data, within_y):
311        """Grid scan + root finding on dRSS/db; returns (b, info dict)."""
312        def rss_of(b):
313            return self._profile(data, within_y, b)[0]
314
315        grid = np.linspace(self.b_bracket[0], self.b_bracket[1], self.b_grid_points)
316        grid_rss = np.array([rss_of(b) for b in grid])
317        best = int(np.argmin(grid_rss))
318        info = {"grid": grid, "grid_rss": grid_rss, "boundary": False, "iterations": 0,
319                "history": np.array([grid[best]]), "root_finder": self.root_finder}
320        if best in (0, grid.size - 1):
321            # The lowest RSS is at an end of the bracket: no interior minimum.
322            info["boundary"] = True
323            return float(grid[best]), info
324
325        def derivative(b):
326            return central_difference(rss_of, b)
327
328        left, right = float(grid[best - 1]), float(grid[best + 1])
329        try:
330            if self.root_finder == "bisection":
331                root = bisection(derivative, left, right, xtol=self.b_xtol, ftol=self.b_ftol)
332            elif self.root_finder == "secant":
333                root = secant(derivative, left, right, xtol=self.b_xtol, ftol=self.b_ftol)
334            else:
335                root = newton(derivative, lambda b: central_second_difference(rss_of, b),
336                              float(grid[best]), xtol=self.b_xtol, ftol=self.b_ftol)
337        except NoSignChangeError:
338            # RSS is flat between the neighbours (no measurable slope): the
339            # grid point is the best available estimate.
340            info["no_sign_change"] = True
341            return float(grid[best]), info
342        info["iterations"] = root.iterations
343        info["history"] = root.history
344        if not self.b_bracket[0] <= root.root <= self.b_bracket[1]:
345            raise ValueError(f"The {self.root_finder} search left the b bracket (b = {root.root}).")
346        return float(root.root), info

348    def fit(self, tyre_age, lap_time, stint_id=None):
349        """Fit a, b and the stint offsets (see the module docstring).
350
351        Parameters
352        ----------
353        tyre_age : array_like
354            Tyre age [laps] of each lap, >= 0 (whole laps for solver "rk4").
355        lap_time : array_like
356            Fuel-corrected lap time [s] of each lap, > 0.
357        stint_id : array_like or None, optional
358            Stint identifier per lap; None = one stint.
359
360        Returns
361        -------
362        WearODEModel
363            ``self``, fitted.
364
365        Raises
366        ------
367        ValueError
368            For invalid inputs, too few laps, no tyre-age variation within
369            stints, or a search that leaves the bracket.
370
371        Example
372        -------
373        >>> WearODEModel("C3").fit([1, 2, 3, 4], [80.0, 80.1, 80.2, 80.3]).params()["n_laps"]
374        4
375        """
376        data = prepare_stint_data(tyre_age, lap_time, stint_id)
377        dof = check_degrees_of_freedom(data, 2)
378        within_y = data.demean(data.lap_time)
379
380        b, search = self._search_b(data, within_y)
381        rss, a, clamped = self._profile(data, within_y, b)
382        g = self._unit_response(data.tyre_age, b)
383
384        self._data = data
385        self._dof = dof
386        self._a, self._b = a, b
387        self._rss = rss
388        self._a_clamped = clamped
389        self._search = search
390        self._offsets = data.stint_means(data.lap_time - a * g)
391        self._standard_errors = self._analytic_standard_errors(data, within_y, a, b, rss, dof)
392        # Verify the numerical solution against the exact one at the fitted b.
393        self._ode_check = float(np.max(np.abs(a * (g - exact_unit_response(data.tyre_age, b)))))
394        self._fitted = True
395        self.bootstrap_result = None
396        self._constraint = check_non_negative(self.degradation, float(data.tyre_age.max()),
397                                              self.negative_tolerance_s,
398                                              ages=np.arange(0.0, data.tyre_age.max() + 1.0))
399        return self

401    def _analytic_standard_errors(self, data, within_y, a, b, rss, dof):
402        """Gauss-Newton standard errors of (a, b): sqrt(diag(sigma^2 (J^T J)^-1)).
403
404        J holds the derivatives of the within-transformed model a g_b(n) with
405        respect to a (that is g_b) and b (a dg_b/db, by central difference).
406        Undefined (NaN) when a was clamped to 0, because b then has no effect.
407        """
408        if a == 0.0:
409            return np.array([np.nan, np.nan])
410
411        def within_unit_response(bb):
412            return data.demean(self._unit_response(data.tyre_age, float(bb)))
413
414        jacobian = np.column_stack([within_unit_response(b),
415                                    a * central_difference(within_unit_response, b)])
416        try:
417            lu, permutation = lu_factor(jacobian.T @ jacobian)
418        except SingularMatrixError:
419            return np.array([np.nan, np.nan])
420        covariance = rss / dof * lu_solve(lu, permutation, np.eye(2))
421        return np.sqrt(np.diag(covariance))

459            Tyre age(s) [laps], >= 0.

488        """Fitted base lap time of every training stint [s] (new tyre, fuel-corrected).

494
495        Raises
496        ------

499
500        Example
501        -------
502        >>> model.stint_offsets()["2023_hungarian_grand_prix|VER|2"]  # doctest: +SKIP

402    def _analytic_standard_errors(self, data, within_y, a, b, rss, dof):
403        """Gauss-Newton standard errors of (a, b): sqrt(diag(sigma^2 (J^T J)^-1)).
404
405        J holds the derivatives of the within-transformed model a g_b(n) with
406        respect to a (that is g_b) and b (a dg_b/db, by central difference).
407        Undefined (NaN) when a was clamped to 0, because b then has no effect.
408        """
409        if a == 0.0:
410            return np.array([np.nan, np.nan])
411
412        def within_unit_response(bb):
413            return data.demean(self._unit_response(data.tyre_age, float(bb)))
414
415        jacobian = np.column_stack([within_unit_response(b),
416                                    a * central_difference(within_unit_response, b)])
417        try:
418            lu, permutation = lu_factor(jacobian.T @ jacobian)
419        except SingularMatrixError:
420            return np.array([np.nan, np.nan])
421        covariance = rss / dof * lu_solve(lu, permutation, np.eye(2))
422        return np.sqrt(np.diag(covariance))
