tyredeg.validation

Validation: metrics, race-wise splits, cross-validation, model selection and checks.

Why splits are by RACE, never by random lap (DECISIONS.md D48)

Laps are not independent. Laps of one stint share the stint's base pace (offset) and have correlated noise (lag-1 residual correlation ~0.45, D45), and all stints of a race share track, weather and car-development conditions. If laps were split at random, every test lap would have neighbours from the same stint and race in the training set: the model could effectively "look up" the answer and the measured error would be far too optimistic. Holding out WHOLE races measures what we actually need - how well the model predicts a race it has never seen.

How a held-out stint is predicted (D49)

Its base pace is unknown, so the first anchor_laps (3) clean laps of the stint are used to estimate it: offset = mean(lap_time - d(tyre_age)) over those laps. The remaining laps are predicted as offset + d(tyre_age) and only they are scored. This mirrors a real race, where a team knows its pace after a few laps on a new set.

Model selection (D48) uses leave-one-race-out cross-validation on the TRAINING races only. The test race is evaluated once, by a separate stage that refuses to run before the selection has been written (D55).

  54def _errors(actual, predicted):
  55    """Return (actual, predicted) as checked float arrays."""
  56    actual = np.asarray(actual, dtype=float).reshape(-1)
  57    predicted = np.asarray(predicted, dtype=float).reshape(-1)
  58    if actual.size == 0:
  59        raise ValueError("actual must not be empty.")
  60    if actual.size != predicted.size:
  61        raise ValueError(f"actual and predicted differ in length ({actual.size} vs {predicted.size}).")
  62    if not (np.all(np.isfinite(actual)) and np.all(np.isfinite(predicted))):
  63        raise ValueError("actual and predicted must not contain NaN or infinite values.")
  64    return actual, predicted

  67def rmse(actual, predicted):
  68    """Root-mean-square error sqrt(mean((predicted - actual)^2)) [s].
  69
  70    The primary metric (D47): it is the quantity least squares minimises and
  71    it penalises large misses more than small ones.
  72
  73    Parameters
  74    ----------
  75    actual : array_like of float
  76        Observed lap times [s]; non-empty and finite.
  77    predicted : array_like of float
  78        Predicted lap times [s]; same length, finite.
  79
  80    Returns
  81    -------
  82    float
  83        RMSE [s], >= 0.
  84
  85    Raises
  86    ------
  87    ValueError
  88        For empty, mismatched or non-finite inputs.
  89
  90    Example
  91    -------
  92    >>> round(rmse([1, 2, 3, 4], [1, 3, 2, 6]), 6)
  93    1.224745
  94    """
  95    actual, predicted = _errors(actual, predicted)
  96    return float(np.sqrt(np.mean((predicted - actual) ** 2)))

  99def mae(actual, predicted):
 100    """Mean absolute error mean(|predicted - actual|) [s].

 157def bias(actual, predicted):
 158    """Mean signed error mean(predicted - actual) [s/lap]; > 0 means too slow.
 159
 160    Strategy adds up lap times, so a consistent bias accumulates over a stint
 161    (0.1 s/lap over 35 laps = 3.5 s); hence the acceptance criterion (D51).
 162
 163    Parameters
 164    ----------
 165    actual : array_like of float
 166        Observed lap times [s]; non-empty and finite.
 167    predicted : array_like of float
 168        Predicted lap times [s]; same length, finite.
 169
 170    Returns
 171    -------
 172    float
 173        Bias [s/lap]; positive when the model predicts slower laps than observed.
 174
 175    Raises
 176    ------
 177    ValueError
 178        For empty, mismatched or non-finite inputs.
 179
 180    Example
 181    -------
 182    >>> bias([1, 2, 3, 4], [1, 3, 2, 6])
 183    0.5
 184    """
 185    actual, predicted = _errors(actual, predicted)
 186    return float(np.mean(predicted - actual))

 189def r_squared(actual, predicted):
 190    """Coefficient of determination 1 - SS_res / SS_tot (NaN if actual is constant).
 191
 192    Note: anchoring each stint's base pace already explains much of the
 193    lap-time variance, so R^2 is high even for the baseline; it is reported
 194    but not used for selection (D47).
 195
 196    Parameters
 197    ----------
 198    actual : array_like of float
 199        Observed lap times [s]; non-empty and finite.
 200    predicted : array_like of float
 201        Predicted lap times [s]; same length, finite.
 202
 203    Returns
 204    -------
 205    float
 206        R^2 (dimensionless, <= 1; negative if worse than the mean); NaN if ``actual`` is constant.
 207
 208    Raises
 209    ------
 210    ValueError
 211        For empty, mismatched or non-finite inputs.
 212
 213    Example
 214    -------
 215    >>> round(r_squared([1, 2, 3, 4], [1, 3, 2, 6]), 6)
 216    -0.2
 217    """
 218    actual, predicted = _errors(actual, predicted)
 219    total = float(np.sum((actual - actual.mean()) ** 2))
 220    if total == 0.0:
 221        return float("nan")
 222    return 1.0 - float(np.sum((predicted - actual) ** 2)) / total

 263@dataclass(frozen=True)
 264class Fold:
 265    """One train/test split. Races are identified by their RaceId.
 266
 267    Attributes
 268    ----------
 269    train_races : tuple of str
 270        Races used for fitting.
 271    test_races : tuple of str
 272        Races used for scoring; none of them may be a training race.
 273
 274    Raises
 275    ------
 276    ValueError
 277        If a race is in both sets, or either set is empty.
 278
 279    Example
 280    -------
 281    >>> Fold(("r1", "r2"), ("r3",)).test_races
 282    ('r3',)
 283    >>> Fold(("r1",), ("r1",))
 284    Traceback (most recent call last):
 285    ...
 286    ValueError: A race cannot be in both train and test: ['r1'].
 287    """
 288
 289    train_races: tuple
 290    test_races: tuple
 291
 292    def __post_init__(self):
 293        overlap = set(self.train_races) & set(self.test_races)
 294        if overlap:
 295            raise ValueError(f"A race cannot be in both train and test: {sorted(overlap)}.")
 296        if not self.train_races or not self.test_races:
 297            raise ValueError("A fold needs at least one training and one test race.")

 300def leave_one_race_out(race_ids):
 301    """One fold per race: test on that race, train on all the others.
 302
 303    Parameters
 304    ----------
 305    race_ids : iterable of str
 306        Race identifiers (duplicates are ignored), at least 2 distinct.
 307
 308    Returns
 309    -------
 310    list of Fold
 311        In sorted race order.
 312
 313    Raises
 314    ------
 315    ValueError
 316        If fewer than 2 distinct races are given.
 317
 318    Example
 319    -------
 320    >>> [fold.test_races for fold in leave_one_race_out(["r1", "r2", "r1", "r3"])]
 321    [('r1',), ('r2',), ('r3',)]
 322    """
 323    races = sorted(set(race_ids))
 324    if len(races) < 2:
 325        raise ValueError("Leave-one-race-out needs at least 2 races.")
 326    return [Fold(tuple(r for r in races if r != held_out), (held_out,)) for held_out in races]

 329def holdout_split(race_ids, test_races):
 330    """Train on every race except ``test_races``; test on ``test_races``.
 331
 332    Parameters
 333    ----------
 334    race_ids : iterable of str
 335        Race identifier of every lap (duplicates are ignored).
 336    test_races : iterable of str
 337        Races to hold out; each must be in ``race_ids``.
 338
 339    Returns
 340    -------
 341    Fold
 342        Races sorted alphabetically within each set.
 343
 344    Raises
 345    ------
 346    ValueError
 347        If a test race is not among ``race_ids`` or nothing is left to train on.
 348
 349    Example
 350    -------
 351    >>> holdout_split(["r1", "r2", "r3"], ["r3"])
 352    Fold(train_races=('r1', 'r2'), test_races=('r3',))
 353    """
 354    races = sorted(set(race_ids))
 355    test = tuple(sorted(set(test_races)))
 356    unknown = set(test) - set(races)
 357    if unknown:
 358        raise ValueError(f"Test races not found in the data: {sorted(unknown)}.")
 359    return Fold(tuple(r for r in races if r not in test), test)

 362def fold_masks(laps, fold, race_column=RACE_COLUMN):
 363    """Boolean masks (train, test) selecting the laps of a fold's races.
 364
 365    Parameters
 366    ----------
 367    laps : pandas.DataFrame
 368        Laps with a race-identifier column.
 369    fold : Fold
 370        The split.
 371    race_column : str, optional
 372        Name of the race column (default ``"RaceId"``).
 373
 374    Returns
 375    -------
 376    train, test : numpy.ndarray of bool
 377        One entry per lap.
 378
 379    Raises
 380    ------
 381    TypeError
 382        If ``laps`` is not a DataFrame or ``fold`` is not a Fold.
 383    ValueError
 384        If the race column is missing, or a lap ends up in both sets
 385        (impossible with a valid Fold; checked anyway).
 386
 387    Example
 388    -------
 389    >>> laps = pd.DataFrame({"RaceId": ["r1", "r2"]})
 390    >>> [m.tolist() for m in fold_masks(laps, Fold(("r1",), ("r2",)))]
 391    [[True, False], [False, True]]
 392    """
 393    if not isinstance(laps, pd.DataFrame):
 394        raise TypeError(f"laps must be a DataFrame, got {type(laps).__name__}.")
 395    if not isinstance(fold, Fold):
 396        raise TypeError(f"fold must be a Fold, got {type(fold).__name__}.")
 397    if race_column not in laps.columns:
 398        raise ValueError(f"laps has no {race_column!r} column.")
 399    train = laps[race_column].isin(fold.train_races).to_numpy()
 400    test = laps[race_column].isin(fold.test_races).to_numpy()
 401    if np.any(train & test):
 402        raise ValueError("A lap is in both the training and the test set.")
 403    return train, test

 448def candidate_models(compound, models):
 449    """All candidates of Phase 5 for one compound (D48).
 450
 451    Parameters
 452    ----------
 453    compound : str
 454        Pirelli code, e.g. "C3".

 481            f"polynomial degree {degree}", "polynomial", degree, 0,
 482            lambda a, t, s, d=degree: PolynomialDegradationModel(compound, degree=d).fit(a, t, s)))
 483    specs.append(ModelSpec(

 488        for k in models.candidate_k:
 489            specs.append(ModelSpec(
 490                f"knn k={k} {weights}", "knn", 10, k,
 491                lambda a, t, s, k=k, w=weights: KNNDegradationModel(compound, k=k, weights=w).fit(a, t, s)))
 492    return specs

 495def predict_held_out(model, laps, anchor_laps):
 496    """Anchor each stint's base pace on its first laps; predict the rest (D49).
 497
 498    Parameters
 499    ----------
 500    model : object
 501        Anything with ``degradation(tyre_age)`` -> d [s].
 502    laps : pandas.DataFrame
 503        Held-out laps with RaceId, StintId, LapNumber, TyreLife and
 504        FuelCorrectedTime.
 505    anchor_laps : int
 506        Number of first clean laps per stint used for the offset (>= 1).
 507        Stints with no laps left after the anchor are skipped.
 508
 509    Returns
 510    -------
 511    pandas.DataFrame
 512        One row per scored lap: RaceId, StintId, LapNumber, TyreLife,
 513        actual, predicted, residual (= predicted - actual).
 514
 515    Raises
 516    ------
 517    ValueError
 518        If ``anchor_laps`` < 1 or no lap could be scored.
 519
 520    Example
 521    -------
 522    >>> class Linear:
 523    ...     def degradation(self, n):
 524    ...         return 0.1 * np.asarray(n, dtype=float)
 525    >>> laps = pd.DataFrame({"RaceId": "r", "StintId": "s", "LapNumber": [1.0, 2.0, 3.0],
 526    ...                      "TyreLife": [1.0, 2.0, 3.0], "FuelCorrectedTime": [80.1, 80.2, 80.4]})
 527    >>> predict_held_out(Linear(), laps, anchor_laps=2)["predicted"].round(6).tolist()
 528    [80.3]
 529
 530    Implementation (Phase 8, D80): the original version looped over stints,
 531    building pandas objects and calling the model twice per stint; profiling
 532    showed it took 67 % of the cross-validation time. This version calls the
 533    model ONCE for all laps and finds every stint's offset at once with
 534    ``numpy.bincount`` (per-stint sums). It returns the same rows in the
 535    same order; :func:`predict_held_out_loop` keeps the original for the
 536    equivalence test and the before/after benchmark.
 537    """
 538    if isinstance(anchor_laps, bool) or not isinstance(anchor_laps, (int, np.integer)) or anchor_laps < 1:
 539        raise ValueError(f"anchor_laps must be an integer >= 1, got {anchor_laps!r}.")
 540    ordered = laps.sort_values([STINT_COLUMN, LAP_COLUMN], kind="stable").reset_index(drop=True)
 541    # Position of each lap within its stint: 0, 1, 2, ... (laps are sorted).
 542    position = ordered.groupby(STINT_COLUMN, sort=False).cumcount().to_numpy()
 543    is_anchor = position < anchor_laps
 544    _, stint_index = np.unique(ordered[STINT_COLUMN].to_numpy(), return_inverse=True)
 545    ages = ordered[AGE_COLUMN].to_numpy(float)
 546    actual_all = ordered[TIME_COLUMN].to_numpy(float)
 547    degradation = np.asarray(model.degradation(ages), dtype=float)
 548
 549    # Offset of each stint = mean over its anchor laps of (lap time - d(age)).
 550    n_stints = int(stint_index.max()) + 1
 551    anchor_sums = np.bincount(stint_index[is_anchor], weights=(actual_all - degradation)[is_anchor],
 552                              minlength=n_stints)
 553    anchor_counts = np.bincount(stint_index[is_anchor], minlength=n_stints)
 554    offsets = anchor_sums / anchor_counts
 555
 556    scored = ~is_anchor
 557    if not np.any(scored):
 558        raise ValueError(f"No stint has more than {anchor_laps} laps; nothing to score.")
 559    predicted = offsets[stint_index[scored]] + degradation[scored]
 560    actual = actual_all[scored]
 561    rest = ordered[scored]
 562    return pd.DataFrame({
 563        RACE_COLUMN: rest[RACE_COLUMN].to_numpy(), STINT_COLUMN: rest[STINT_COLUMN].to_numpy(),
 564        LAP_COLUMN: rest[LAP_COLUMN].to_numpy(float), AGE_COLUMN: ages[scored],
 565        "actual": actual, "predicted": predicted, "residual": predicted - actual,
 566    })

 598    -------
 599    >>> laps = pd.DataFrame({"RaceId": "r1", "StintId": "r1|A|1", "LapNumber": [1.0, 2.0, 3.0, 4.0],
 600    ...                      "TyreLife": [1.0, 2.0, 3.0, 4.0], "FuelCorrectedTime": [80.1, 80.2, 80.3, 80.5]})
 601    >>> class Linear:
 602    ...     def degradation(self, n):
 603    ...         return 0.1 * np.asarray(n, dtype=float)
 604    >>> scored = predict_held_out_loop(Linear(), laps, 3)
 605    >>> scored[["actual", "predicted"]].round(6).values.tolist()
 606    [[80.5, 80.4]]
 607    """
 608    if isinstance(anchor_laps, bool) or not isinstance(anchor_laps, (int, np.integer)) or anchor_laps < 1:
 609        raise ValueError(f"anchor_laps must be an integer >= 1, got {anchor_laps!r}.")
 610    pieces = []
 611    ordered = laps.sort_values([STINT_COLUMN, LAP_COLUMN], kind="stable")
 612    for _, stint in ordered.groupby(STINT_COLUMN, sort=False):
 613        anchor, rest = stint.iloc[:anchor_laps], stint.iloc[anchor_laps:]
 614        if rest.empty:
 615            continue
 616        anchor_age = anchor[AGE_COLUMN].to_numpy(float)
 617        offset = float(np.mean(anchor[TIME_COLUMN].to_numpy(float) - model.degradation(anchor_age)))
 618        predicted = offset + model.degradation(rest[AGE_COLUMN].to_numpy(float))
 619        actual = rest[TIME_COLUMN].to_numpy(float)
 620        pieces.append(pd.DataFrame({
 621            RACE_COLUMN: rest[RACE_COLUMN].to_numpy(), STINT_COLUMN: rest[STINT_COLUMN].to_numpy(),
 622            LAP_COLUMN: rest[LAP_COLUMN].to_numpy(float), AGE_COLUMN: rest[AGE_COLUMN].to_numpy(float),
 623            "actual": actual, "predicted": predicted, "residual": predicted - actual,
 624        }))
 625    if not pieces:
 626        raise ValueError(f"No stint has more than {anchor_laps} laps; nothing to score.")
 627    return pd.concat(pieces, ignore_index=True)

 674def cross_validate(laps, spec, folds, anchor_laps, implementation="vectorised"):
 675    """Evaluate one candidate on every fold.
 676
 677    Parameters
 678    ----------
 679    laps : pandas.DataFrame
 680        Clean laps of ONE compound from the TRAINING races only.
 681    spec : ModelSpec
 682        The candidate to evaluate.
 683    folds : list of Fold
 684        E.g. :func:`leave_one_race_out`; at least one.
 685    anchor_laps : int
 686        First laps per held-out stint used to set its base pace (D49), >= 1.
 687    implementation : str, optional
 688        "vectorised" (default, :func:`predict_held_out`) or "loop" (the
 689        original :func:`predict_held_out_loop`, for the Phase 8 benchmark).
 690
 691    Returns
 692    -------
 693    fold_table : pandas.DataFrame
 694        One row per fold with the metrics, or ``applicable = False`` if the
 695        fold had too few training laps for this candidate.
 696    predictions : pandas.DataFrame
 697        All scored laps of all folds (with a ``fold`` column).
 698
 699    Raises
 700    ------
 701    ValueError
 702        For an unknown ``implementation``, an empty ``folds`` list, or invalid
 703        laps (see :func:`fit_on` and :func:`predict_held_out`).
 704
 705    Example
 706    -------
 707    >>> ages = np.tile(np.arange(1.0, 9.0), 6)
 708    >>> laps = pd.DataFrame({"RaceId": np.repeat(["r1", "r2", "r3"], 16), "StintId": np.repeat([f"s{i}" for i in range(6)], 8),
 709    ...                      "LapNumber": ages, "TyreLife": ages, "FuelCorrectedTime": 80.0 + 0.06 * ages + 0.05 * np.sin(7 * ages)})
 710    >>> from tyredeg.config import load_config
 711    >>> spec = candidate_models("C3", load_config("config.yaml").models)[1]
 712    >>> table, scored = cross_validate(laps, spec, leave_one_race_out(laps["RaceId"]), 3)
 713    >>> table[["test_race", "rmse"]].round(6).values.tolist()
 714    [['r1', 0.019808], ['r2', 0.019808], ['r3', 0.019808]]
 715    """
 716    if len(folds) == 0:
 717        raise ValueError("folds must contain at least one Fold.")
 718    predictors = {"vectorised": predict_held_out, "loop": predict_held_out_loop}
 719    if implementation not in predictors:
 720        raise ValueError(f"implementation must be one of {sorted(predictors)}, got {implementation!r}.")
 721    predictor = predictors[implementation]
 722    rows, predictions = [], []
 723    for number, fold in enumerate(folds):
 724        train_mask, test_mask = fold_masks(laps, fold)
 725        train, test = laps[train_mask], laps[test_mask]
 726        row = {"model": spec.name, "family": spec.family, "fold": number,
 727               "test_race": ",".join(fold.test_races)}
 728        if len(train) < spec.min_training_laps:
 729            rows.append({**row, "applicable": False})
 730            continue
 731        scored = predictor(fit_on(spec, train), test, anchor_laps)
 732        scored["fold"] = number
 733        predictions.append(scored)
 734        rows.append({**row, "applicable": True,
 735                     **compute_metrics(scored["actual"], scored["predicted"])})
 736    combined = pd.concat(predictions, ignore_index=True) if predictions else pd.DataFrame()
 737    return pd.DataFrame(rows), combined

 740def summarize_folds(fold_table, max_abs_bias):
 741    """Mean +/- standard error over folds per model, plus the D51 checks.
 742
 743    Columns: model, family, rmse_mean, rmse_se, mae_mean, max_abs_error_max,
 744    r_squared_mean, bias_mean, bias_max_abs_fold, beats_baseline_all_folds,
 745    bias_ok. Candidates not applicable in every fold are dropped.
 746
 747    Parameters
 748    ----------
 749    fold_table : pandas.DataFrame
 750        The concatenated ``fold_table`` outputs of :func:`cross_validate`
 751        for every candidate, including the baseline.
 752    max_abs_bias : float
 753        Largest accepted |mean bias| [s/lap], >= 0 (config: 0.10).
 754
 755    Returns
 756    -------
 757    pandas.DataFrame
 758        One row per candidate, with the columns listed above.
 759
 760    Raises
 761    ------
 762    TypeError
 763        If ``fold_table`` is not a DataFrame.
 764    ValueError
 765        If a required column or the baseline is missing, or ``max_abs_bias`` < 0.
 766
 767    Example
 768    -------
 769    >>> ages = np.tile(np.arange(1.0, 9.0), 6)
 770    >>> laps = pd.DataFrame({"RaceId": np.repeat(["r1", "r2", "r3"], 16), "StintId": np.repeat([f"s{i}" for i in range(6)], 8),
 771    ...                      "LapNumber": ages, "TyreLife": ages, "FuelCorrectedTime": 80.0 + 0.06 * ages + 0.05 * np.sin(7 * ages)})
 772    >>> from tyredeg.config import load_config
 773    >>> specs = candidate_models("C3", load_config("config.yaml").models)[:2]   # baseline, degree 1
 774    >>> tables = [cross_validate(laps, spec, leave_one_race_out(laps["RaceId"]), 3)[0] for spec in specs]
 775    >>> summary = summarize_folds(pd.concat(tables), max_abs_bias=0.10)
 776    >>> summary[["model", "beats_baseline_all_folds", "bias_ok"]].values.tolist()
 777    [['baseline (no degradation)', False, False], ['polynomial degree 1', True, True]]
 778    """
 779    if not isinstance(fold_table, pd.DataFrame):
 780        raise TypeError(f"fold_table must be a DataFrame, got {type(fold_table).__name__}.")
 781    required = ("model", "family", "fold", "applicable", "rmse", "mae", "max_abs_error", "r_squared", "bias")
 782    missing = [column for column in required if column not in fold_table.columns]
 783    if missing:
 784        raise ValueError(f"fold_table is missing columns: {missing}")
 785    if not (fold_table["model"] == BASELINE_NAME).any():
 786        raise ValueError(f"fold_table has no {BASELINE_NAME!r} rows; every candidate is compared with it.")
 787    if not max_abs_bias >= 0:
 788        raise ValueError(f"max_abs_bias must be >= 0 s/lap, got {max_abs_bias}.")
 789    applicable = fold_table.groupby("model")["applicable"].transform("all")
 790    table = fold_table[applicable.astype(bool)]
 791    baseline = table[table["model"] == BASELINE_NAME].set_index("fold")["rmse"]
 792    rows = []
 793    for (model, family), group in table.groupby(["model", "family"], sort=False):
 794        folds = group.set_index("fold")
 795        rows.append({
 796            "model": model, "family": family,
 797            "rmse_mean": folds["rmse"].mean(),
 798            "rmse_se": folds["rmse"].std(ddof=1) / np.sqrt(len(folds)),
 799            "mae_mean": folds["mae"].mean(),
 800            "max_abs_error_max": folds["max_abs_error"].max(),
 801            "r_squared_mean": folds["r_squared"].mean(),
 802            "bias_mean": folds["bias"].mean(),
 803            "bias_max_abs_fold": folds["bias"].abs().max(),
 804            "beats_baseline_all_folds": bool(np.all(folds["rmse"] < baseline.loc[folds.index])),
 805            "bias_ok": abs(folds["bias"].mean()) <= max_abs_bias,
 806        })
 807    return pd.DataFrame(rows)

 810def select_models(summary, complexity):
 811    """Selection rule (D48): best per family, then the one-standard-error rule.
 812
 813    1. Within each family the candidate with the lowest mean CV RMSE wins.
 814    2. Among the family winners (baseline excluded), take the best mean RMSE
 815       and its standard error; choose the SIMPLEST winner whose mean RMSE is
 816       within one standard error of the best (ties in simplicity: lower RMSE).
 817
 818    Parameters
 819    ----------
 820    summary : pandas.DataFrame
 821        Output of :func:`summarize_folds`.
 822    complexity : dict
 823        Model name -> complexity (lower = simpler).
 824
 825    Returns
 826    -------
 827    dict
 828        ``family_winners`` (family -> model name), ``selected`` (model name),
 829        ``best_rmse``, ``best_rmse_se``, ``threshold``.
 830
 831    Raises
 832    ------
 833    ValueError
 834        If there is no non-baseline candidate.
 835
 836    Example
 837    -------
 838    >>> s = pd.DataFrame({"model": ["p1", "p3", "k"], "family": ["poly", "poly", "knn"],
 839    ...                   "rmse_mean": [0.64, 0.62, 0.63], "rmse_se": [0.05, 0.05, 0.05]})
 840    >>> # p1 and p3 are one family: only p3 (lower RMSE) goes forward. Best
 841    >>> # winner p3 = 0.62 +/- 0.05; k (0.63) is also within 1 SE, but p3 is simpler.
 842    >>> select_models(s, {"p1": 1, "p3": 3, "k": 10})["selected"]
 843    'p3'
 844    """
 845    candidates = summary[summary["family"] != "baseline"]
 846    if candidates.empty:
 847        raise ValueError("No candidate model to select from.")
 848    winners = candidates.loc[candidates.groupby("family", sort=False)["rmse_mean"].idxmin()]
 849    best = winners.loc[winners["rmse_mean"].idxmin()]
 850    threshold = best["rmse_mean"] + best["rmse_se"]
 851    eligible = winners[winners["rmse_mean"] <= threshold].copy()
 852    eligible["complexity"] = eligible["model"].map(complexity)
 853    chosen = eligible.sort_values(["complexity", "rmse_mean"]).iloc[0]
 854    return {
 855        "family_winners": dict(zip(winners["family"], winners["model"])),
 856        "selected": chosen["model"],
 857        "best_rmse": float(best["rmse_mean"]),
 858        "best_rmse_se": float(best["rmse_se"]),
 859        "threshold": float(threshold),
 860    }

 866@dataclass(frozen=True)
 867class MonotonicCheck:
 868    """Result of :func:`check_monotonic`.
 869
 870    Attributes
 871    ----------
 872    largest_drop_s : float
 873        Largest fall of d between consecutive tyre ages [s] (negative if d
 874        always rises).
 875    n_drops_over_tolerance : int
 876        Number of consecutive-age drops larger than the tolerance.
 877    ok : bool
 878        True if there are none.
 879    tolerance_s : float
 880        The tolerance used [s].
 881
 882    Example
 883    -------
 884    >>> check = check_monotonic(lambda n: -0.1 * n, 3.0, 0.05)
 885    >>> check.ok, check.n_drops_over_tolerance, round(check.largest_drop_s, 6)
 886    (False, 3, 0.1)
 887    """
 888
 889    largest_drop_s: float
 890    n_drops_over_tolerance: int
 891    ok: bool
 892    tolerance_s: float
 893
 894
 895def check_monotonic(degradation, max_age, tolerance_s):
 896    """Check that d(n) does not fall by more than ``tolerance_s`` from lap to lap.
 897
 898    Parameters
 899    ----------
 900    degradation : callable
 901        d(ages) [s].
 902    max_age : float
 903        Oldest tyre age to check [laps]; ages 0, 1, ..., floor(max_age).
 904    tolerance_s : float
 905        Allowed drop between consecutive laps [s], >= 0 (config: 0.05 s,
 906        about the noise of an average over one tyre age, 0.45/sqrt(59)).
 907
 908    Returns
 909    -------
 910    MonotonicCheck
 911
 912    Raises
 913    ------
 914    TypeError
 915        If ``degradation`` is not callable.
 916    ValueError
 917        If ``max_age`` is negative or not finite, or ``tolerance_s`` < 0.
 918
 919    Example
 920    -------
 921    >>> check_monotonic(lambda n: 0.07 * n, 40.0, 0.05).ok
 922    True
 923    """
 924    if not callable(degradation):
 925        raise TypeError("degradation must be callable, d(ages) -> degradation [s].")
 926    if not np.isfinite(max_age) or max_age < 0:
 927        raise ValueError(f"max_age must be a finite number of laps >= 0, got {max_age}.")
 928    if not tolerance_s >= 0:
 929        raise ValueError("tolerance_s must be >= 0.")
 930    ages = np.arange(0.0, np.floor(max_age) + 1.0)
 931    drops = -np.diff(np.asarray(degradation(ages), dtype=float))
 932    largest = float(np.max(drops)) if drops.size else 0.0
 933    count = int(np.sum(drops > tolerance_s))
 934    return MonotonicCheck(largest, count, count == 0, float(tolerance_s))

 974# 5. Residual analysis (D54)
 975# ---------------------------------------------------------------------------
 976def binned_residuals(values, residuals, bin_edges):
 977    """Mean residual (+/- standard error) in bins of ``values`` (tyre age or lap number).
 978
 979    A lap belongs to the bin (low, high]: above the lower edge, up to and
 980    including the upper edge.
 981
 982    Parameters
 983    ----------
 984    values : array_like of float
 985        Binning variable of each lap, e.g. tyre age [laps].
 986    residuals : array_like of float
 987        Residual (predicted - actual) of each lap [s]; same length.
 988    bin_edges : sequence of float
 989        At least 2 strictly increasing edges.
 990
 991    Returns
 992    -------
 993    pandas.DataFrame
 994        Columns bin_low, bin_high, n, mean, se. A trend across bins shows a
 995        systematic error the model has not captured.
 996
 997    Raises
 998    ------
 999    ValueError
1000        If ``values`` and ``residuals`` differ in length, or ``bin_edges`` has
1001        fewer than 2 values or is not strictly increasing.
1002
1003    Example
1004    -------
1005    >>> binned_residuals([1, 2, 11, 12], [0.1, -0.1, 0.5, 0.7], [0, 10, 20])["mean"].round(3).tolist()
1006    [0.0, 0.6]
1007    """
1008    values = np.asarray(values, dtype=float).reshape(-1)
1009    residuals = np.asarray(residuals, dtype=float).reshape(-1)
1010    if values.size != residuals.size:
1011        raise ValueError(f"values and residuals differ in length ({values.size} vs {residuals.size}).")
1012    edges = np.asarray(bin_edges, dtype=float)
1013    if edges.ndim != 1 or edges.size < 2 or np.any(np.diff(edges) <= 0):
1014        raise ValueError("bin_edges must contain at least 2 strictly increasing values.")
1015    rows = []
1016    for low, high in zip(bin_edges[:-1], bin_edges[1:]):
1017        inside = (values > low) & (values <= high)
1018        n = int(inside.sum())
1019        mean = float(residuals[inside].mean()) if n else float("nan")
1020        se = float(residuals[inside].std(ddof=1) / np.sqrt(n)) if n > 1 else float("nan")
1021        rows.append({"bin_low": low, "bin_high": high, "n": n, "mean": mean, "se": se})
1022    return pd.DataFrame(rows)

1052    upper: float
1053    flagged: bool

1056
1057def leftover_fuel_effect(laps, compounds, n_resamples, confidence_level, seed):
1058    """Estimate any fuel effect left after fuel correction (D54).
1059
1060    Within a stint, lap number and tyre age both rise by 1 per lap, so a
1061    per-stint model cannot separate them. Here each DRIVER-RACE gets one
1062    offset shared by all its stints: tyre age resets at a pit stop but lap
1063    number does not, so the coefficient on lap number is identifiable. With
1064    fuel-corrected times it estimates (k_fuel - true fuel effect) [s/lap]:
1065    zero if the fuel correction is right. Uncertainty: bootstrap that
1066    resamples whole driver-races (the units that own an offset).
1067
1068    Parameters
1069    ----------
1070    laps : pandas.DataFrame
1071        Clean laps with RaceId, Driver, TyreLife, LapNumber,
1072        FuelCorrectedTime and PirelliCompound.
1073    compounds : sequence of str
1074        Compounds included (each gets its own tyre-age slope).
1075    n_resamples : int
1076        Bootstrap resamples (>= 2).
1077    confidence_level : float
1078        In (0, 1).
1079    seed : int
1080        Random seed (rule 11).
1081
1082    Returns
1083    -------
1084    FuelDiagnostic
1085        ``flagged`` is True if the interval excludes 0.
1086
1087    Raises
1088    ------
1089    ValueError
1090        For invalid settings or no usable laps.
1091
1092    Example
1093    -------
1094    >>> leftover_fuel_effect(clean, ["C3", "C4"], 200, 0.95, 42).flagged  # doctest: +SKIP
1095    False
1096    """
1097    data = laps[laps["PirelliCompound"].isin(compounds)]
1098    if data.empty:
1099        raise ValueError("No laps of the requested compounds.")
1100    if n_resamples < 2 or not 0 < confidence_level < 1:
1101        raise ValueError("Need n_resamples >= 2 and 0 < confidence_level < 1.")
1102    groups = (data[RACE_COLUMN].astype(str) + "|" + data["Driver"].astype(str)).to_numpy()
1103    arrays = {
1104        "age": data[AGE_COLUMN].to_numpy(float), "lap": data[LAP_COLUMN].to_numpy(float),
1105        "time": data[TIME_COLUMN].to_numpy(float), "compound": data["PirelliCompound"].to_numpy(),
1106    }
1107
1108    def slope(selection, labels):
1109        """Coefficient on lap number for the laps in ``selection``, grouped by ``labels``."""
1110        _, index = np.unique(labels, return_inverse=True)
1111        counts = np.bincount(index)
1112
1113        def demean(values):
1114            # Within transformation: subtract each driver-race group's mean.
1115            return values - (np.bincount(index, weights=values) / counts)[index]
1116
1117        age, lap = arrays["age"][selection], arrays["lap"][selection]
1118        compound, time = arrays["compound"][selection], arrays["time"][selection]
1119        columns = [demean(np.where(compound == c, age, 0.0)) for c in compounds]
1120        columns.append(demean(lap))
